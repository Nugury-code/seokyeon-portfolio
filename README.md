# 원석연 포트폴리오

[공개 포트폴리오 바로가기](https://nugury-code.github.io/seokyeon-portfolio/)

보안·IT 기술지원 분야의 경험과 프로젝트를 소개하는 정적 웹사이트입니다.

## 파일 구성

- `index.html`: 페이지 내용
- `style.css`: 디자인
- `app.js`: 인증서·프로젝트 확대 창과 이메일 복사 등 동작
- `assets/`: 프로필 사진, 배경, 로고, 확인 코드를 비공개 처리한 인증서
- `fonts/`: Pretendard 글꼴과 라이선스

HTML·CSS·JavaScript와 이미지 파일을 그대로 게시하는 웹사이트입니다. 이미지는 확인 코드를 제거한 공개용 자료만 포함합니다. 코드가 있는 증서 원본·이력서 원본·취업 관리 파일·접속 토큰·호스팅 설정·기존 Git 기록은 포함하지 않습니다.

프로젝트 상세 자료와 시연 영상은 추후 보완할 예정입니다. 기술 목록은 실제 프로젝트 수행 범위를 확인해 갱신합니다.

사진과 개인 콘텐츠는 포트폴리오 소유자의 자료입니다. 아이콘·글꼴의 이용 조건은 각 라이선스 파일을 참고하세요.

## ASTRA 시연 영상

브루트포스·퇴사자 계정 접근·권한 밖 접근·SQL Injection 네 시연 영상을 프로젝트 상세에서 재생할 수 있습니다. 영상·썸네일은 assets/projects/astra/에 두고 project-astra-media.js에서 연결합니다. Python 탐지 구현·VM 배포와 팀 대응·보고서 기능을 구분해 소개합니다.
